Telegram-бот расписания 26-CS-1

Бот получает личное расписание EKTU и отправляет только занятия **всей группы** и **1-й подгруппы**. Занятия 2-й и других подгрупп он не показывает.

## Что умеет

- `/today` — расписание на сегодня;
- `/tomorrow` — расписание на завтра;
- `/week` — расписание на неделю;
- автоматическое сообщение утром и расписание на завтра вечером.
