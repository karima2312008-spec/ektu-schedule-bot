# Telegram-бот расписания 26-CS-1

Бот получает личное расписание EKTU и отправляет только занятия **всей группы** и **1-й подгруппы**. Занятия 2-й и других подгрупп он не показывает.

## Что умеет

- `/today` — расписание на сегодня;
- `/tomorrow` — расписание на завтра;
- `/week` — расписание на неделю;
- автоматическое сообщение утром и расписание на завтра вечером.

## До начала

Вам понадобятся компьютер с Windows, доступ в личный кабинет EKTU и Telegram. Секреты — пароль от вуза, токен Telegram и cookie — никому не отправляйте, включая этот чат.

## Шаг 1. Установите Python

1. Откройте [python.org/downloads/windows](https://www.python.org/downloads/windows/).
2. Скачайте актуальный установщик Python 3 для Windows и запустите его.
3. В самом первом окне **обязательно** отметьте `Add python.exe to PATH`.
4. Нажмите `Install Now` и дождитесь окончания установки.
5. Закройте и снова откройте PowerShell или Windows Terminal.
6. Напишите `py --version` и нажмите Enter. Если появилась версия Python, всё готово.

## Шаг 2. Создайте Telegram-бота

1. В Telegram найдите официального бота `@BotFather`.
2. Отправьте ему `/newbot`.
3. Введите отображаемое имя, например `Расписание Карима`.
4. Введите уникальное имя пользователя, которое заканчивается на `bot`, например `karim_ektu_schedule_bot`.
5. BotFather пришлёт токен, похожий на длинную строку с двоеточием. Скопируйте его в безопасное место. Это пароль от управления ботом.

## Шаг 3. Подготовьте папку проекта

1. Откройте папку с этим проектом в Проводнике.
2. Найдите файл `.env.example`.
3. Скопируйте его и переименуйте копию в `.env` — именно без `.example` в конце.
   - Если Windows не показывает расширения файлов: в Проводнике откройте «Вид» → «Показать» → «Расширения имён файлов».
4. Откройте `.env` в Блокноте.
5. После знака `=` у строки `TELEGRAM_BOT_TOKEN=` вставьте токен из BotFather.
6. Пока оставьте `OWNER_CHAT_ID=` пустой.

Пример — токен здесь вымышленный:

```text
TELEGRAM_BOT_TOKEN=123456789:AAExampleToken_DoNotUse
OWNER_CHAT_ID=
```

Сохраните файл и закройте Блокнот.

## Шаг 4. Установите компоненты бота

1. Откройте папку проекта.
2. Кликните в строку пути сверху, напишите `powershell` и нажмите Enter. Откроется синее или чёрное окно уже в нужной папке.
3. Выполните эти две команды по очереди:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Первая команда создаст отдельное окружение для бота. Вторая установит нужные компоненты. Это делается один раз.

## Шаг 5. Первый запуск на сохранённом примере

Этот режим не обращается к сайту — он нужен, чтобы убедиться, что Telegram-бот работает.

1. Откройте `.env` ещё раз.
2. Уберите `#` в начале этой строки и оставьте путь к сохранённой вами странице:

```text
SCHEDULE_HTML_FILE=C:/Users/Карим/Downloads/https___www.do.ektu.kz_Protected_spa_DScheduleSemestr.htm
```

3. В PowerShell запустите:

```powershell
.\.venv\Scripts\python.exe bot.py
```

4. Откройте своего бота в Telegram и отправьте `/start`.
5. Он ответит вашим `chat ID`, например `123456789`.
6. Остановите программу в PowerShell сочетанием `Ctrl+C`.
7. Вставьте этот номер после `OWNER_CHAT_ID=` в `.env`, сохраните файл.
8. Снова выполните команду запуска и отправьте боту `/today`.

Если появилось расписание без второй подгруппы — Telegram-часть готова.

## Шаг 6. Подключите живое расписание сайта

Когда тест пройдёт, удалите или закомментируйте строку `SCHEDULE_HTML_FILE=...` в `.env`. Тогда бот при каждом запросе будет загружать актуальную страницу EKTU.

Есть два варианта авторизации:

1. Если сайт принимает логин и пароль в стандартном запросе, заполните локально:

```text
SCHEDULE_USERNAME=ваш_логин_в_вузе
SCHEDULE_PASSWORD=ваш_пароль_в_вузе
```

2. Если вход на сайте работает только через браузерную сессию, понадобится строка `SCHEDULE_COOKIE=`. Её не нужно и нельзя пересылать в чат: она даёт доступ к кабинету. Попросите меня помочь настроить этот шаг локально, не раскрывая её в переписке.

После изменения `.env` перезапустите бота. Проверьте `/today`; если он показывает актуальные занятия, всё подключено.

## Шаг 7. Автоматический запуск при входе в Windows

1. Нажмите клавишу Windows, введите «Планировщик заданий» и откройте его.
2. Справа нажмите «Создать задачу».
3. На вкладке «Общие» задайте имя: `Telegram расписание`.
4. На вкладке «Триггеры» нажмите «Создать» → выберите «При входе в систему» → «ОК».
5. На вкладке «Действия» нажмите «Создать».
6. В поле «Программа или сценарий» выберите файл `run_bot.cmd` из этой папки.
7. Нажмите «ОК», затем ещё раз «ОК» для сохранения задачи.

Компьютер должен быть включён и подключён к интернету в моменты утренней и вечерней рассылок.

## Безопасность

- `.env` — личный файл: не пересылайте его и не выкладывайте в облачные репозитории.
- Токен из BotFather, пароль от вуза и `SCHEDULE_COOKIE` дают доступ к вашим сервисам.
- Если токен Telegram оказался у постороннего, сразу выполните `/revoke` в `@BotFather` и замените его в `.env`.
